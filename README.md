# 🎉 Birthday Wish Website
A beautiful and interactive Birthday Wish Website built using HTML, CSS, and JavaScript.
This project delivers a personalized birthday greeting with smooth animations, visual effects, and an auto-rotating photo to create a memorable experience.

✨ Features
🎂 Beautiful birthday greeting
🖼️ Auto-rotating birthday photo
🎨 Smooth CSS animations and transitions
✨ Interactive visual effects
📱 Responsive design for desktop and mobile
⚡ Lightweight and fast
# 🛠️ Built With
HTML5 – Structure
CSS3 – Styling and animations
JavaScript – Interactive functionality

# 🚀 How to Run Locally
Clone the repository:
git clone ``https://github.com/blackarchparrot/birthday-wish.git``
Open the project folder.
Open index.html in your web browser.
